## 1. 系统概览

### 1.1 项目简介

Mujica F1 Modeler 是一套用于模拟完整 F1 比赛周末的系统，覆盖自由练习赛（FP1/FP2/FP3）、排位赛（Q1/Q2/Q3）、冲刺赛和正赛。系统采用**混合模拟方法**：确定性计算与随机骰子元素结合，产生适合叙事创作的比赛结果。

### 1.2 系统架构

```
main.py (入口)
├── src/practice/       自由练习赛
├── src/qualifying/     排位赛
├── src/sprint/         冲刺赛
├── src/simulation/     正赛模拟引擎
├── src/tyre/           轮胎退化模型
├── src/drs/            DRS 与超车系统
├── src/incidents/      事故系统
├── src/weather/        天气系统
├── src/strategist/     AI 策略师
├── src/skills/         车手技能
├── src/penalties/      处罚系统
├── src/core/           核心数学模型
└── src/utils/          工具函数
```

### 1.3 比赛周末流程

**标准周末：** FP1 → FP2 → FP3 → 排位赛 → 正赛

**冲刺周末：** FP1 → 排位赛 → FP2 → 冲刺赛 → 正赛

每个环节的结果会影响后续环节（例如排位赛决定正赛发车格，练习赛调校影响排位赛表现）。

## 2. 核心数学模型

### 2.1 R 值体系

整个系统的核心是一个统一的评分体系，用 **R 值** 衡量车手+赛车的综合实力。

#### DR（车手评分）

- 来源：`data/driver_ratings.csv`
- 范围：约 99.5 ~ 100.5
- 含义：代表车手的纯粹驾驶技术，与赛车无关
- 示例：Verstappen 100.5、Hamilton 100.4、Leclerc 100.4

#### PR（赛车性能评分）

- 来源：`data/spain_team.csv`
- 计算公式：

$$PR = C_M \times Mech + C_A \times Aero + C_P \times Power$$

其中：
- **Mech**（机械抓地力）：制动性能、机械抓地力，范围 88~100
- **Aero**（空气动力学效率）：下压力效率，范围 87~101
- **Power**（动力单元）：引擎功率，范围 97~101
- $C_M, C_A, C_P$ 是赛道系数，根据赛道特性调整各组件的权重

#### R 值（综合评分）

$$R = \frac{DR \times PR}{100}$$

示例：Verstappen (DR=100.5) + Red Bull (PR=308.34) → R = 100.5 × 308.34 / 100 = 309.88

### 2.2 赛道系数

每条赛道有独特的 $C_M, C_A, C_P$ 系数，用于调整各车队赛车属性的权重：

| 系数 | 含义 | 计算方法 |
|------|------|----------|
| $C_M$（机械需求） | 基于重制动弯道比例 | <35%: 1.0, 35-40%: 1.05, >40%: 1.1 |
| $C_A$（空力需求） | 基于倍耐力下压力评级 | 5级(高): 1.0, 3级: 1.05, 1级(低): 1.1 |
| $C_P$（动力需求） | 基于全油门百分比 | ≤70%: 1.0, 70-80%: 1.05, ≥80%: 1.1 |

**效果示例：**
- 蒙扎（高速赛道）：$C_A=1.1, C_P=1.1$ → 强调空力效率和引擎功率
- 摩纳哥（慢速街道赛）：$C_M=1.1$ → 强调机械抓地力

### 2.3 圈速计算

#### 基础圈速公式

$$t_{base} = TRACK\_BASE - (R - 300) \times 0.01$$

- $TRACK\_BASE$ 是赛道基准时间（例如西班牙 89.0s，摩纳哥 79.6s）
- 参考 R = 300；R 每高 1 点，圈速快 0.01s

#### 非线性 T-R 模型

更精确的圈速计算使用非线性模型：

$$t = t_{base} \times \left(1 + \alpha \times \left(1 - \frac{R}{R_{max}}\right) \times \exp\left(-\gamma \times \left(1 - \frac{R}{R_{max}}\right)\right)\right)$$

其中：
- $\alpha = 0.65$（退化幅度系数）
- $\gamma = 2.5$（退化速率系数）
- $R_{max}$ 是全场最高 R 值

这个模型的特点是：在 R 值接近最大值时产生**边际递减效应**，更接近真实的 F1 性能分布。

### 2.4 R 值补偿系统

为了平衡同一车队内 1 号和 2 号车手的差距，系统对 2 号车手进行隐藏补偿：

$$R_{compensated} = R_{base} + compensation$$

$$compensation = \min\left((R_{leader} - R_{base}) \times 0.5, \ max\_compensation\right)$$

| 车队层级 | 最大补偿值 |
|----------|-----------|
| 顶级车队（红牛、法拉利、梅赛德斯、迈凯伦、阿斯顿马丁） | 0.35 |
| 中游车队（阿尔派恩、威廉姆斯） | 0.25 |
| 下游车队（AlphaTauri、Alfa Romeo、哈斯） | 0.15 |

### 2.5 圈速噪声模型

实际圈速会加入随机噪声，模拟真实比赛中的圈速波动：

#### 马尔可夫噪声过程

$$noise_{new} = noise_{old} \times 0.6 \times consistency\_factor + \mathcal{N}(0, \sigma_{effective} \times 0.3)$$

- 噪声标准差取决于车手 DR 百分位：精英车手 0.01-0.02s，中等 0.02-0.04s，较低 0.04-0.08s
- PR（赛车质量）影响方差：顶级赛车 ×0.92，低级赛车 ×1.18
- 马尔可夫因子 0.6 产生"状态连续性"——快圈之后更可能继续快，慢圈之后更可能继续慢

## 3. 轮胎退化模型

### 3.1 复合退化公式

轮胎退化采用**乘法退化模型**，包含三个组件：

#### 基础退化（指数衰减）

$$M_{base}(lap) = 1 + a \times (1 - e^{-k_1 \times lap}) + b \times (1 - e^{-k_2 \times lap})$$

- $a, b$：退化幅度系数
- $k_1, k_2$：退化速率常数
- 两个指数项分别捕捉快速初始退化和缓慢长期磨损

#### 悬崖效应（Sigmoid 函数）

$$M_{cliff}(lap) = cliff\_magnitude \times \frac{1}{1 + e^{-cliff\_steepness \times (lap - cliff\_lap)}}$$

- $cliff\_lap$：悬崖效应开始的圈数
- $cliff\_magnitude$：悬崖严重程度
- $cliff\_steepness = 2.5$（固定值，控制悬崖陡峭度）

#### 总退化乘数

$$M_{total}(lap) = M_{base}(lap) + M_{cliff}(lap)$$

### 3.2 各配方参数对比

| 配方 | $a$ | $k_1$ | $b$ | $k_2$ | 悬崖圈数 | 悬崖幅度 | 特点 |
|------|-----|-------|-----|-------|----------|----------|------|
| C1（最硬） | 0.010 | 0.05 | 0.035 | 0.010 | 45 | 0.025 | 退化最慢，悬崖最晚 |
| C2 | 0.015 | 0.08 | 0.050 | 0.015 | 35 | 0.040 | 均衡性能 |
| C3（中性） | 0.025 | 0.10 | 0.070 | 0.020 | 28 | 0.060 | 标准比赛轮胎 |
| C4 | 0.040 | 0.15 | 0.090 | 0.030 | 22 | 0.090 | 初期抓地力好，退化快 |
| C5（最软） | 0.065 | 0.20 | 0.130 | 0.040 | 15 | 0.150 | 退化最快，悬崖最早最猛 |

### 3.3 配方间性能差距

| 配方对比 | 圈速差距 |
|----------|----------|
| C5 vs C4 | 0.55-0.70s |
| C4 vs C3 | 0.40-0.50s |
| C3 vs C2 | 0.30-0.40s |
| C2 vs C1 | 0.20-0.30s |
| C5→C1 总计 | ~1.4-1.9s/圈 |

### 3.4 赛道与压力补偿

考虑赛道特性和胎压设定时：

$$M_{compensated} = 1 + (M_{uncompensated} - 1) \times W_{track} \times P_{setup}$$

- $W_{track}$：赛道磨损系数，$= 1 + 0.2 \times \frac{abrasion - 3}{2}$
- $P_{setup}$：胎压惩罚，$= 1 + 0.0125 \times (pressure\_deviation)^2$

### 3.5 温度修正

$$k_{corrected} = k \times e^{-\alpha \times (T_{track} - T_{opt})}$$

- $\alpha = 0.015 \sim 0.025$ /°C
- 温度每升高 10°C，悬崖提前 1-2 圈
- 软配方（C4-C5）对温度更敏感

### 3.6 非线性 R 值缩放

更好的车手能更充分地利用轮胎：

$$scaled\_lap = base\_lap \times \left(1 + 0.65 \times \left(1 - \frac{R}{R_{max}}\right) \times e^{-2.5 \times (1 - \frac{R}{R_{max}})}\right)$$

高 R 值车手的轮胎有效寿命更长。

## 4. 比赛模拟引擎

### 4.1 主循环结构

正赛模拟的核心循环在 `enhanced_long_dist_sim.py` 的 `run_simulation()` 方法中：

1. **初始化**：加载车手数据，生成策略（1停或2停），确定进站圈数，分配轮胎配方序列
2. **发车模拟**：模拟静止起步，包含反应时间、起步质量、格位惩罚
3. **逐圈循环**（对每个未退赛车手）：
   - 天气更新
   - 事故检查（赛车故障、车手失误）
   - 超车检查
   - 进站处理
   - 圈速计算（基础圈速 + 轮胎退化 + 噪声 + 配方差异 + 事故损失 + SC/VSC 效果）
   - 安全车/VSC 处理
   - 套圈检测
4. **最终成绩**：按有效圈数和累计时间排序
5. **输出**：CSV 结果、骰子记录、Markdown 报告

### 4.2 发车模拟

发车模拟包含以下因素：

#### 格位惩罚

| 位置 | 时间惩罚 |
|------|----------|
| 杆位 | 0.0s |
| P2 | 0.05s |
| 第一排 | 0.1s |
| 第二排 | 0.18s |
| 第三排 | 0.28s |
| 第四排 | 0.4s |
| 第5-8排 | 0.55s + (pos-11)×0.08s |
| 第9排+ | 0.85s + (pos-16)×0.10s |

#### 反应时间

使用 d10 骰子决定：
- 1 = 非常慢
- 10 = 极佳

受车手个性特质（侵略性、稳定性）修正。

#### 起步质量

d10 骰子：
- 1 = 重大失误（严重延迟）
- 2 = 打滑
- 3-8 = 正常
- 9-10 = 完美起步

#### 赛道直道影响

| 分类 | 直道长度 | 基础时间惩罚 | 示例赛道 |
|------|----------|-------------|----------|
| 长直道 | >1000m | 0.8s | 巴林、意大利 |
| 中直道 | 600-1000m | 1.2s | 西班牙、澳大利亚 |
| 短直道 | <600m | 2.0s | 摩纳哥、阿塞拜疆 |

#### 特殊事件概率

- 起步失误：$\max(0.005, 0.03 - consistency \times 0.02)$，损失 0.4-1.0s
- 完美起步：$\min(0.015, 0.005 + consistency \times 0.01)$，收益 0.15-0.4s
- 格位碰撞风险：前 6 排有 $0.02 \times \frac{6 - grid\_position + 1}{6}$ 的概率

### 4.3 进站系统

#### 策略确定

- 基线分布：50% 一停，50% 两停
- 基于历史 2022-2024 数据的加权随机选择
- 平滑贝叶斯评分模型分析过去模拟结果
- 摩纳哥特殊规则：95% 一停（仅 5% 两停）

#### 进站圈生成

| 策略 | 进站圈（占总圈数比例） |
|------|----------------------|
| 一停 | ~60% |
| 两停 | ~35% 和 ~70% |
| 三停 | ~30%, ~55%, ~80% |

实际进站圈使用历史数据并加入 ±10 圈随机偏差。

#### 进站时间计算（骰子系统）

**第一阶段 — D10：**

| 骰子 | 概率 | 结果 | 时间范围 |
|------|------|------|----------|
| 1-2 | 20% | 快速换胎 | 2.0-2.3s |
| 3-7 | 50% | 正常换胎 | 2.3-3.0s |
| 8-9 | 20% | 缓慢换胎 | 3.0-3.5s |
| 10 | 10% | 进入第二阶段 | 特殊 |

**第二阶段 — D2（仅 D10=10 时触发）：**

| 骰子 | 总概率 | 结果 | 时间范围 |
|------|--------|------|----------|
| 1 | 5% | 大成功（出色配合） | 1.8-2.0s |
| 2 | 5% | 大失败（问题进站） | 3.5-15.0s |

大失败使用截断正态分布 $\mathcal{N}(6.0, 2.0^2)$，截断至 [3.5, 15] 秒。

**总进站时间：**

$$t_{pit} = t_{pitlane} + t_{tire\_change} + t_{front\_wing}$$

- $t_{pitlane}$：赛道维修区时间（来自 `pitlane_time.csv`，典型值 22-25s）
- 安全车下：-10s
- VSC 下：-6s

#### 前翼更换

进站时如果车手有前翼损坏，d10 骰子决定是否更换，更换会增加额外时间。

## 5. DRS 与超车系统

### 5.1 DRS 区域配置

每个 DRS 区域定义 6 个参数：
- `zone_id`：唯一标识符
- `start_distance` / `end_distance`：区域起止距离（米）
- `detection_point`：DRS 资格检测点（米）
- `base_time_gain`：DRS 激活时的预期时间收益（典型 0.03-0.20s）
- `activation_probability`：激活概率（默认 85%）

### 5.2 DRS 资格规则

1. 第一圈禁用 DRS
2. 第 2 圈后启用
3. 车手在检测点必须在前车 1 秒以内
4. 仅限指定区域使用

### 5.3 DRS 收益计算

$$gain = zone.base\_time\_gain + \mathcal{U}(-variation, +variation)$$

激活概率检查：$\text{random}() > activation\_probability$ 时收益为 0。

### 5.4 超车触发概率

超车系统采用**两层架构**：

#### 第一层：触发系统

$$P = P_{base} \times M_{lap} \times M_{DRS} \times M_{gap} \times M_{section} \times M_{consecutive} \times M_{density}$$

**各赛道基础概率：**

| 赛道 | 基础概率 | 预期超车数/场 |
|------|----------|--------------|
| 蒙扎 | 0.0003 | 50-70 |
| 银石 | 0.0012 | 20-30 |
| 摩纳哥 | 0.00002 | 0-2 |
| 默认 | 0.0008-0.0010 | 30-50 |

**修正函数：**

| 修正类型 | 条件 | 倍数 |
|----------|------|------|
| 圈数修正 | 前3圈 | ×1.5 |
| | 最后10% | ×1.3 |
| | 进站窗口(35-50%) | ×1.2 |
| DRS修正 | 在DRS区域内 | ×2.0 |
| 差距修正 | ≤0.3s | ×2.5 |
| | ≤0.5s | ×1.8 |
| | ≤1.0s | ×1.0 |
| | ≤2.0s | ×0.4 |
| | >2.0s | ×0.05 |
| 路段修正 | DRS区域 | ×1.8 |
| | 直道 | ×1.3 |
| | 弯道入口 | ×1.1 |
| | S弯 | ×1.15 |
| | 弯道出口 | ×0.9 |
| | 发夹弯 | ×0.4 |
| 密度修正 | ≥4车在范围内 | ×2.0 |
| | ≥2车 | ×1.3 |
| 连续惩罚 | 每次连续超车 | ×0.15 |

#### 第二层：对抗系统

超车尝试使用**对抗骰子机制**解决：

$$Attacker_{total} = 1d10 + DR_{attack} + Situation\_mods$$
$$Defender_{total} = 1d10 + DR_{defend} + Situation\_mods$$

- 高者胜
- 平局防守方胜

**三种对抗场景：**

**A. DRS 区域内：**
- 进攻方：$1d10 + \frac{DR_{attack}-80}{2} + 3(\text{有DRS时}) + Speed\_Delta$
- 防守方：$1d10 + \frac{DR_{defend}-80}{2} - 3(\text{对方有DRS时}) + Grip$

**B. DRS 区域末端（弯道入口）：**
- 进攻方：$1d10 + \frac{DR_{attack}-80}{2} + Corner\_Exit\_Mod + Brake\_Mod$
- 防守方：$1d10 + \frac{DR_{defend}-80}{2} + Line\_Mod + Defensive\_Mod$

**C. 其他位置：**
- 双方：$1d10 + \frac{DR-80}{2} + Precision + Experience$

#### 推进机制（Push）

当进攻方以 ≤3 差距失败且轮胎较新（$tyre\_degradation < 1.15$）时：

$$New_{attacker} = Attacker_{total} + 1d6$$

- 若新值 > 防守方 → 进攻方胜
- 代价：无论结果如何，+2 轮胎退化

### 5.5 车手 DR 对超车的影响

| DR 值 | 修正值 | 描述 |
|-------|--------|------|
| 80 | -5.0 | 低于平均 |
| 86 | +0.0 | 平均 |
| 90 | +4.0 | 优秀 |
| 92 | +6.0 | 精英 |

DR 还影响：
- 制动控制：$\frac{DR-80}{12}$（范围 0-3）
- 抓地力/牵引力：$\frac{DR-82}{10}$（范围 0-2）
- 防守线路：$\frac{DR-80}{12}$（范围 0-3）

## 6. 事故系统

### 6.1 事故类型与概率

| 事故类型 | 基础概率 | 触发机制 |
|----------|----------|----------|
| 超车碰撞 | 5%（每次超车尝试） | 超车触发系统 |
| 车手失误 | 3%（每圈） | 基于 DR 的概率 |
| 赛车故障 | ~0.7-2%（整场） | 稳定性骰子（10d100） |
| 反击碰撞 | 30% 基础（限幅 10-60%） | 超车后反击 |

### 6.2 车手失误概率

$$P_{error} = P_{base} - \frac{DR - 80}{40} \times 0.02$$

**修正因子：**

| 条件 | 修正 |
|------|------|
| 轮胎退化 > 1.2 | ×1.5 |
| 轮胎退化 > 1.1 | ×1.2 |
| 位置 ≤ 3（领先者） | ×0.8 |
| 位置 ≥ 15（后方） | ×1.2 |
| 承受压力 | ×1.3 |
| 第一圈 | ×1.5 |
| 前3圈 | ×1.2 |

**R 值覆盖：**
- R ≥ 100.0：固定 0.1%（几乎无失误）
- R ≥ 99.5：固定 0.5%（极低失误率）

**骰子解决：** d20 对抗 DR 计算的阈值（DR 92 → 阈值 21，上限 20）

| 骰子结果 | 严重程度 |
|----------|----------|

### 6.3 赛车故障系统

#### 稳定性检查（10d100 骰子）

|----------|------|
| 1-800 | 无事发生 |
| 801-900 | 车手失误 |
| 901-1000 | 机械故障 |

**稳定性 ≥ 96 的赛车：**

|----------|------|
| 1-900 | 无事发生 |
| 901-950 | 车手失误 |
| 951-1000 | 机械故障 |

#### 故障概率公式

$$P_{fault} = stability\_factor + pu\_factor + distance\_factor + damage\_factor$$

其中：
- $stability\_factor = \frac{100 - base\_stability}{250}$
- $pu\_factor = \frac{laps\_on\_pu}{50} \times 0.01$
- $distance\_factor = \frac{race\_distance\_km}{300} \times 0.005$
- $damage\_factor = 0.02$（如有事故损伤）

总概率限幅至 0.5%-8%。

## 14. 套圈与解套系统

### 14.1 蓝旗系统

**状态：** 无 → 警告 → 最终 → 已遵守 → 违规

**触发条件：**
- 被套车与领先者差距 < 3.0s：警告
- 差距 < 1.5s：最终
- 领先者圈数更高
- 两车在同一或相邻计时段

### 14.2 遵守系统（d20 骰子）

基础目标值 = 15（75% 遵守率）。

**修正因子：**

| 因素 | 修正值 |
|------|--------|
| DR 85+（每 5 点） | +1 到 +3 |
| 后方车队 | +2 |
| 冠军争夺者 | -1 |
| 首次出示蓝旗 | +1 |
| 重复旗帜（挫败感） | -(次数-2) |
| 赛道路段（直道/DRS） | +2 |
| 弯道入口 | -2 |
| 弯道顶点 | -5 |
| 制动区 | -3 |
| 比赛末段（90%+） | -2 |
| 队友 | +3 |
| 同盟车队 | +1 |
| 对手 | -2 |

### 14.3 解套程序（FIA 规则）

安全车下解套流程：
1. SC 出动 → 检查被套车辆
2. 比赛控制根据 SC 时长、被套车数量、赛道条件、剩余圈数决定授权
3. 宣布"被套车辆可以超车"
4. 被套车超越领先者和 SC，重新加入队尾
5. 最后一辆被套车超越领先者后下一圈 SC 进站
6. 比赛恢复

**条件：** 最少 3 圈 SC、干燥条件、最少 5 圈剩余、最多 10 辆车。

## 15. 叙事辅助系统

### 15.1 系统目的

可选的概率平衡系统，用于故事驱动的模拟（如同人创作），让指定"主角队"获得更叙事满意的结果。

### 15.2 启用方式

```bash
# 环境变量控制
set F1_NARRATIVE_ASSIST=subtle  # 或 moderate, strong
set F1_ASSIST_TARGET=Ferrari    # 默认法拉利
```

### 15.3 强度预设

| 参数 | subtle | moderate | strong |
|------|--------|----------|--------|
| 概率偏移 | 15% | 30% | 50% |
| 成功率提升 | 10% | 20% | 35% |
| 逆境减少 | 10% | 25% | 40% |

### 15.4 核心机制

1. **加权 d20**：目标队获得偏向高值的加权分布
   - 面 1：权重 0.4（极不可能）
   - 面 16-19：权重 1.0 + shift×0.45
   - 面 20：权重 1.0 + shift×0.65
   - 对手获得反向加权

2. **失误概率**：目标队失误率按 adversity_reduction 降低

3. **稳定性提升**：目标队稳定性提高，对手降低

4. **策略偏向**：影响 1 停 vs 2 停概率

5. **极强模式**："骰子锁定"——目标队始终掷最高值，对手始终掷 1

### 15.5 隐蔽机制

- **随机应用率**：并非每次掷骰都应用偏置（40-75% 取决于强度）
- **变化偏置强度**：每次应用 ±15% 随机变化
- **动量冷却**：连续 3+ 次成功后，偏置逐级递减
- **关键决策保护**：高风险时刻减少注入（最后 3 圈、冠军决定性比赛）
- **失败保留**：始终保留 10-15% 失败概率

## 16. 数据流与系统集成

### 16.1 完整数据流

```
1. 数据加载
   ├─ 车手评分 → driver_ratings.csv (DR)
   ├─ 车队参数 → spain_team.csv (Mech, Aero, Power)
   └─ 赛道数据 → track_characteristics.csv (C_M, C_A, C_P)

2. R 值计算
   ├─ PR = C_M×Mech + C_A×Aero + C_P×Power
   ├─ R = DR × PR / 100
   └─ 应用 2 号车手补偿

3. 比赛周末流程
   ├─ FP1/FP2/FP3 → 调校骰子 → R 值修正 (±0.5)
   ├─ 排位赛 → Q1/Q2/Q3 → 发车格
   ├─ 冲刺赛（如有）→ 冲刺结果
   └─ 正赛
       ├─ 发车模拟（反应时间 + 格位惩罚）
       ├─ 逐圈循环
       │   ├─ 天气更新
       │   ├─ 事故检查（骰子）
       │   ├─ 超车检查（概率 + 对抗骰子）
       │   ├─ 进站处理
       │   ├─ 圈速计算（基础 + 退化 + 噪声 + 配方 + 事故 + SC/VSC）
       │   └─ 技能激活检查
       ├─ 最终成绩（按有效圈数和累计时间排序）
       └─ 输出（CSV + Markdown 报告）

4. 叙事辅助（可选）
   └─ 概率平衡器介入骰子结果
```

### 16.2 环节间依赖关系

| 上游环节 | 下游环节 | 数据传递 |
|----------|----------|----------|
| 练习赛 | 排位赛/正赛 | 调校 R 值修正 |
| 排位赛 | 正赛 | 发车格位置 |
| 冲刺排位赛 | 冲刺赛 | 冲刺发车格 |
| 冲刺赛 | 正赛 | 正赛发车格（可选） |
| 正赛模拟 | 策略分析 | 历史结果用于策略权重调整 |

### 16.3 输出文件

系统生成以下输出：
- `outputs/` 目录下的 CSV 结果文件
- 骰子记录 CSV
- Markdown 格式比赛报告
- 可视化图表（圈速散点图、位置变化图）
