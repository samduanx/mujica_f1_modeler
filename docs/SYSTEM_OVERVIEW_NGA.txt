[collapse=2. 核心数学模型]

[h]2.1 R 值体系[/h]

整个系统的核心是一个统一的评分体系，用 [b]R 值[/b] 衡量车手+赛车的综合实力。

[h]DR（车手评分）[/h]

[list]
[*]范围：约 99.5 ~ 100.5
[*]含义：代表车手的纯粹驾驶技术，与赛车无关
[*]示例：Verstappen 100.5、Hamilton 100.4、Leclerc 100.4
[*]该部分与旧版本没有区别
[/list]

[h]PR（赛车性能评分）[/h]

[list]
[*]计算公式：
[/list]

[code]PR = C(M) × Mech + C(A) × Aero + C(P) × Power[/code]

[list]
[*][b]Mech[/b]（机械抓地力）：制动性能、机械抓地力，范围 88~100
[*][b]Aero[/b]（空气动力学效率）：下压力效率，范围 87~101
[*][b]Power[/b]（动力单元）：引擎功率，范围 97~101
[*]C(M), C(A), C(P) 是赛道系数，根据赛道特性调整各组件的权重
[*]该部分与旧版本没有区别，但赛道系数的生成方法有变化，详见下文。
[/list]

[h]R 值（综合评分）[/h]

[code]R = DR × PR / 100[/code]

示例：Verstappen (DR=100.5) + Red Bull (PR=308.34) → R = 100.5 × 308.34 / 100 = [b]309.88[/b]

[h]2.2 赛道系数[/h]

每条赛道有独特的 C(M), C(A), C(P) 系数，用于调整各车队赛车属性的权重：

[table]
[tr][td][b]系数[/b][/td][td][b]含义[/b][/td][td][b]计算方法[/b][/td][/tr]
[tr][td]C(M)（机械需求）[/td][td]基于重制动弯道比例[/td][td]<35%: 1.0, 35-40%: 1.05, >40%: 1.1[/td][/tr]
[tr][td]C(A)（空力需求）[/td][td]基于倍耐力下压力评级[/td][td]5级(高): 1.0, 3级: 1.05, 1级(低): 1.1[/td][/tr]
[tr][td]C(P)（动力需求）[/td][td]基于全油门百分比[/td][td]≤70%: 1.0, 70-80%: 1.05, ≥80%: 1.1[/td][/tr]
[/table]

[b]效果示例：[/b]
[list]
[*]蒙扎（高速赛道）：C(A)=1.1, C(P)=1.1 → 强调空力效率和引擎功率
[*]摩纳哥（慢速街道赛）：C(M)=1.1 → 强调机械抓地力
[/list]

[h]2.3 圈速计算[/h]

[h]基础圈速公式[/h]

[code]t(base) = TRACK_BASE - (R - 300) × 0.01[/code]

[list]
[*]TRACK_BASE 是赛道基准时间（例如西班牙 89.0s，摩纳哥 79.6s）
[*]参考 R = 300；R 每高 1 点，圈速快 0.01s
[/list]

[h]非线性 T-R 模型[/h]

更精确的圈速计算使用非线性模型：

[code]t = t(base) × (1 + α × (1 - R/R(max)) × exp(-γ × (1 - R/R(max))))[/code]

其中：
[list]
[*]α = 0.65（退化幅度系数）
[*]γ = 2.5（退化速率系数）
[*]R(max) 是全场最高 R 值
[/list]

这个模型的特点是：在 R 值接近最大值时产生[b]边际递减效应[/b]，更接近真实的 F1 性能分布。

[h]2.4 R 值补偿系统[/h]

为了平衡同一车队内 1 号和 2 号车手的差距，系统对 2 号车手进行隐藏补偿：

[code]R(compensated) = R(base) + compensation
compensation = min((R(leader) - R(base)) × 0.5,  max_compensation)[/code]

[table]
[tr][td][b]车队层级[/b][/td][td][b]最大补偿值[/b][/td][/tr]
[tr][td]顶级车队（红牛、法拉利、梅赛德斯、迈凯伦、阿斯顿马丁）[/td][td]0.35[/td][/tr]
[tr][td]中游车队（阿尔派恩、威廉姆斯）[/td][td]0.25[/td][/tr]
[tr][td]下游车队（AlphaTauri、Alfa Romeo、哈斯）[/td][td]0.15[/td][/tr]
[/table]

[h]2.5 圈速噪声模型[/h]

实际圈速会加入随机噪声，模拟真实比赛中的圈速波动：

[h]马尔可夫噪声过程[/h]

[code]noise(new) = noise(old) × 0.6 × consistency_factor + N(0, σ(effective) × 0.3)[/code]

[list]
[*]噪声标准差取决于车手 DR 百分位：精英车手 0.01-0.02s，中等 0.02-0.04s，较低 0.04-0.08s
[*]PR（赛车质量）影响方差：顶级赛车 ×0.92，低级赛车 ×1.18
[*]马尔可夫因子 0.6 产生"状态连续性"——快圈之后更可能继续快，慢圈之后更可能继续慢
[/list]

[collapse=3. 轮胎退化模型]

[h]3.1 复合退化公式[/h]

轮胎退化采用[b]乘法退化模型[/b]，包含三个组件：

[h]基础退化（指数衰减）[/h]

[code]M(base)(lap) = 1 + a × (1 - e^(-k1 × lap)) + b × (1 - e^(-k2 × lap))[/code]

[list]
[*]a, b：退化幅度系数
[*]k1, k2：退化速率常数
[*]两个指数项分别捕捉快速初始退化和缓慢长期磨损
[/list]

[h]悬崖效应（Sigmoid 函数）[/h]

[code]M(cliff)(lap) = cliff_magnitude × 1/(1 + e^(-cliff_steepness × (lap - cliff_lap)))[/code]

[list]
[*]cliff_lap：悬崖效应开始的圈数
[*]cliff_magnitude：悬崖严重程度
[*]cliff_steepness = 2.5（固定值，控制悬崖陡峭度）
[/list]

[h]总退化乘数[/h]

[code]M(total)(lap) = M(base)(lap) + M(cliff)(lap)[/code]

[h]3.4 赛道与压力补偿[/h]

考虑赛道特性和胎压设定时：

[code]M(compensated) = 1 + (M(uncompensated) - 1) × W(track) × P(setup)[/code]

[list]
[*]W(track)：赛道磨损系数 = 1 + 0.2 × (abrasion - 3) / 2
[*]P(setup)：胎压惩罚 = 1 + 0.0125 × (pressure_deviation)^2
[/list]

[h]3.5 温度修正[/h]

[code]k(corrected) = k × e^(-α × (T(track) - T(opt)))[/code]

[list]
[*]α = 0.015 ~ 0.025 /°C
[*]温度每升高 10°C，悬崖提前 1-2 圈
[*]软配方（C4-C5）对温度更敏感
[/list]

[h]3.6 非线性 R 值缩放[/h]

更好的车手能更充分地利用轮胎：

[code]scaled_lap = base_lap × (1 + 0.65 × (1 - R/R(max)) × e^(-2.5 × (1 - R/R(max))))[/code]

高 R 值车手的轮胎有效寿命更长。

[collapse=5. DRS 与超车系统]

[h]5.1 DRS 区域配置[/h]

每个 DRS 区域定义 6 个参数：
[list]
[*]zone_id：唯一标识符
[*]start_distance / end_distance：区域起止距离（米）
[*]detection_point：DRS 资格检测点（米）
[*]base_time_gain：DRS 激活时的预期时间收益（典型 0.03-0.20s）
[*]activation_probability：激活概率（默认 85%）
[/list]

[h]5.2 DRS 资格规则[/h]

[list=1]
[*]第一圈禁用 DRS
[*]第 2 圈后启用
[*]车手在检测点必须在前车 1 秒以内
[*]仅限指定区域使用
[/list]

[h]5.3 DRS 收益计算[/h]

[code]gain = zone.base_time_gain + U(-variation, +variation)[/code]

激活概率检查：random() > activation_probability 时收益为 0。

[collapse=15. 数据流与系统集成]

[h]15.1 完整数据流[/h]

[code]
1. 数据加载
   ├─ 车手评分 → driver_ratings.csv (DR)
   ├─ 车队参数 → spain_team.csv (Mech, Aero, Power)
   └─ 赛道数据 → track_characteristics.csv (C_M, C_A, C_P)

2. R 值计算
   ├─ PR = C_M×Mech + C_A×Aero + C_P×Power
   ├─ R = DR × PR / 100
   └─ 应用 2 号车手补偿

3. 比赛周末流程
   ├─ FP1/FP2/FP3 → 调校骰子 → R 值修正 (±0.5)
   ├─ 排位赛 → Q1/Q2/Q3 → 发车格
   ├─ 冲刺赛（如有）→ 冲刺结果
   └─ 正赛
       ├─ 发车模拟（反应时间 + 格位惩罚）
       ├─ 逐圈循环
       │   ├─ 天气更新
       │   ├─ 事故检查（骰子）
       │   ├─ 超车检查（概率 + 对抗骰子）
       │   ├─ 进站处理
       │   ├─ 圈速计算（基础 + 退化 + 噪声 + 配方 + 事故 + SC/VSC）
       │   └─ 技能激活检查
       ├─ 最终成绩（按有效圈数和累计时间排序）
       └─ 输出（CSV + Markdown 报告）

[/code]
